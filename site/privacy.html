Privacy

Last updated 7 October 2026.

This website

memstack.stalewell.com is a static site operated by Stalewell. It sets no cookies, uses no local storage, loads no third-party fonts or scripts, and has no forms or accounts.

Analytics

We measure aggregate traffic with Cloudflare Web Analytics, which is cookieless: it does not use client-side state, does not fingerprint visitors, and does not collect or store personal data such as IP addresses. We see page views, referrers, country and browser type, in aggregate only.

Hosting

The site is served by Cloudflare, which processes request metadata (such as IP address) to deliver pages and protect against abuse, under its own privacy policy.

The MemStack software

MemStack is open-source software that runs on your machine and stores memories where you choose. It does not send your memories to us. Details are in the repository.

Contact

Questions: open an issue. Security reports: see the security policy.
